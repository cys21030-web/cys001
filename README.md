# 升降機平層誤差監察系統

這個專案是一套結合感測器、機器學習與即時視覺化介面的升降機平層監測系統。目標是透過 8x8 矩陣雷達的距離資料，辨識升降機在不同狀態下的特徵，並提供資料採集、模型訓練與即時推論的完整流程。

## 專案目的

- 收集升降機不同運行狀態下的距離資料
- 建立可訓練的分類模型
- 透過 GUI 或 TUI 觀察資料與推論結果
- 提供簡單可重複的實驗流程，方便後續調整與優化

## 主要功能

- 資料採集模式：讀取感測器資料並儲存為標記樣本
- 訓練模式：使用 PyTorch 訓練分類模型
- 推論模式：載入模型並對最新資料做即時判斷
- 視覺化輸出：顯示熱力圖、點雲圖、訓練曲線與訓練影片

## 專案結構

```text
.
├── app_main.py              # 主程式入口，啟動 GUI 與模式切換
├── collector_app.py         # 資料採集模式
├── inference_app.py         # 即時推論模式
├── tui_train.py             # 終端訓練流程
├── AppBase.py               # 共用的 UI 與圖表基礎元件
├── ai/                      # 模型與標籤相關邏輯
│   ├── ToFDataLabel.py      # 標籤定義
│   └── ToFTrainer.py        # 模型訓練與儲存相關邏輯
├── common/                  # 共用資料處理與感測器相關模組
│   ├── ToFData.py           # 距離資料清理與格式處理
│   ├── ToFSensor.py         # 感測器驅動與資料讀取
│   ├── ViewAngle.py         # 視角與投影參數設定
│   └── WorldCoord.py        # 將距離資料轉為 3D 點雲
├── training/                # 訓練資料集與樣本結構定義
├── snapshot/                # 採集後的原始資料樣本

├── docs/                    # HTML 說明文件
└── requirements.txt         # Python 依賴套件
```

## 各主要類別與用途

- MainApp：主控流程，負責啟動主視窗、切換模式與整合子應用程式。
- CollectorApp：採集模式的控制器，負責讀取感測器數據、標記樣本與保存 `.dat` 檔案。
- InferenceApp：推論模式的控制器，負責載入模型、執行每幀推論與顯示結果。
- App：共用 UI 基底類別，提供熱力圖、3D 點雲與設定面板的基本繪圖能力。
- ToFSensor：封裝感測器硬體讀取流程，負責初始化、輪詢並取得最新距離資料。
- ToFData：負責處理原始距離矩陣，包含修復異常值與轉換格式。
- ViewAngle：定義感測器的視角與投影參數，用於把距離資料映射為 3D 座標。
- WorldCoord：將 2D 距離矩陣轉換成 3D 點雲資料，供視覺化使用。
- ToFDataLabel：定義系統中可使用的分類標籤。
- ToFClassifierModel：神經網路模型定義，負責做分類推論。
- ToFSample / ToFDataset：資料集與樣本結構，方便 PyTorch 訓練。

## 使用方式

### 1. 安裝依賴

```bash
python3 -m pip install -r requirements.txt
```

### 2. 採集資料

```bash
python3 app_main.py
```

- 進入「數據採集」模式
- 選擇標籤，例如正常、上樓、下樓或無事件
- 按下開始採集，資料將存入 `snapshot/` 下的對應資料夾

### 3. 訓練模型

```bash
python3 tui_train.py
```

- 系統會掃描 `snapshot/` 中的樣本
- 輸入訓練集比例後開始訓練
- 會輸出模型檔案與訓練統計圖到 `models/`

### 4. 進行推論

```bash
python3 app_main.py
```

- 切換到「實時數據分析」模式
- 選擇已訓練完成的模型
- 即時顯示每個類別的置信度與判定結果

## 注意事項

- 本專案最初設計為搭配樹莓派 4B 與 ToF 雷達硬體使用。
- 若無實體感測器，需先確認資料來源與格式是否正確，避免推論與採集流程中斷。
- 訓練與推論結果會受到資料品質與標註品質影響。
