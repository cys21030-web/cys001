一、 系統總覽

本系統整合了 8x8 矩陣雷達、PyTorch 神經網路與 互動式 GUI / TUI，用於監測電梯在不同物理狀態下的距離特徵，例如正常、上樓、下樓與無事件。系統可分為三個主要階段：資料採集、模型訓練與即時推論。

資料採集

由感測器取得原始距離資料，建立 8×8 特徵矩陣，並透過標記後存為訓練樣本。

模型訓練

使用簡化三層全連接網路，對資料進行 stratified 切分、訓練與輸出模型與統計圖。

即時推論

從最新感測器資料做預處理與展平後輸入模型，輸出每個類別的機率分布與判定結果。

三、 訓練流程說明

訓練流程以純終端機 TUI 形式執行，減少圖形介面與 PyTorch 訓練在同一環境中互相衝突的風險。

  1. 執行 python3 tui_train.py。
  2. 掃描 snapshot/ 中的各類別樣本。
  3. 依序輸入訓練集比例（預設 50%）。
  4. 進行 stratified 切分與隨機打散。
  5. 建立 3 層全連接網路，輸入向量為 64 維（8x8 展平）。
  6. 每個 epoch 都會輸出訓練/驗證損失與準確率。
  7. 產生模型檔案與訓練統計圖表。
  • 輸入維度：64（8 × 8 矩陣）
  • 隱藏層：64 → 64
  • 輸出類別：對應標籤數量
  • 激活函數：ReLU
  • 損失函數：CrossEntropyLoss
  • .pth：模型權重與設定參數
  • .yaml：訓練摘要、樣本數與分割資訊
  • training_stats.png：訓練曲線圖
  • frames/：每個 epoch 的可視化結果圖片
  • training_progress.mp4：由影格組成的訓練動畫影片

四、 推論流程說明

推論模式會載入最新訓練完成的模型，對即時感測資料進行預處理與分類，並將結果以可讀方式呈現。

  1. 啟動主應用程式：python3 app_main.py。
  2. 在主選單切換到「實時數據分析」模式。
  3. 系統自動掃描 models/ 中的模型。
  4. 選擇對應模型後，開始接收感測器資料。
  5. 每個新資料幀都會被展平並送入模型。
  6. 使用 Softmax 取得各類別機率，並顯示最高置信度結果。

系統會依據機率分數判斷是否為明顯結果：若最高類別機率至少達到動態閾值，則以高亮方式顯示；否則顯示為不確定結果。

當分類結果不明確時，介面會以灰色條狀顯示，避免誤導使用者。

五、 執行手冊與建議流程

1. 採集資料

  1. 啟動主視窗後切換到採集模式。
  2. 選擇標籤，例如「正常」、「上樓」、「下樓」或「無事件」。
  3. 點擊開始採集，等待資料指標增加。
  4. 數據會存入 snapshot/ 下對應資料夾。

2. 訓練模型

  1. 確認 snapshot/ 中有足夠多樣樣本。
  2. 執行 python3 tui_train.py。
  3. 依據需求輸入訓練/測試分割比例。
  4. 等待模型輸出。

3. 進行推論

  1. 啟動 python3 app_main.py。
  2. 切換到即時推論模式。
  3. 在模型清單中選擇最新產生的模型。
  4. 監看各類別機率與目前狀態。

4. 建議檢查清單
